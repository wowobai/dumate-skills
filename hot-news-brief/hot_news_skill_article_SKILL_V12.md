# hot_news_skill_article_V12

## 功能
每日热点文娱新闻全流程自动化：搜索新闻 → 去重 → 配图下载 → PPT生成 → 邮件发送(163SMTP) → 公众号草稿创建 → 新闻稿docx生成。

**V12新增：禁止百家号内容 + 200字截断信息完整性保证。**

**V11核心优化：模板引擎与数据分离，每日只写JSON数据文件（~50行），不再重复生成500行脚本。**

## 触发条件
- 每日定时触发（11:20）或用户手动要求"运行"
- 前置条件：前一日产出目录存在（用于去重）

## 工作流程

### 步骤1：搜索新闻 + 去重
1. 读取前一日 `D:\dumate\娱乐新闻\{yyyyMMdd}热点新闻\run_article_v*.py` 提取已用5条标题/关键词
2. 搜索今日热点文娱新闻（websearch，2-3次不同关键词）
3. **禁止搜索百家号内容**：搜索时排除百家号（baijiahao.baidu.com）来源，不采用任何百家号文章作为新闻来源或信息引用
4. 筛选5条不与前一日重复的新闻，每条须有2个以上消息来源（均非百家号）

### 步骤2：生成 news_data.json（仅需~50行）
在 `D:\dumate\娱乐新闻\{yyyyMMdd}热点新闻\` 目录下创建 `news_data.json`：
```json
{
  "date": "20260715",
  "date_display": "2026.07.15",
  "out_dir": "D:\\dumate\\娱乐新闻\\20260715热点新闻",
  "news": [
    {
      "id": "1",
      "title": "新闻标题",
      "body": "正文（150-200字，不含英文引号）",
      "source": "据XXX公布资料",
      "analysis": "分析（100-150字）",
      "data_source": "数据来源：XXX、XXX",
      "image_query": "关键词（2-3词，不含特殊符号）"
    }
  ]
}
```
**注意**：body和analysis中严禁使用英文双引号 `"`，用中文引号 或转义 `\u201c\u201d` 替代。

### 步骤3：运行模板引擎
```bash
python -X utf8 D:\dumate\skills\news_script\run_article_template.py D:\dumate\娱乐新闻\{yyyyMMdd}热点新闻\news_data.json
```
模板引擎自动执行：配图下载 → PPT生成 → 邮件发送 → 公众号草稿创建

### 步骤4：生成新闻稿docx
```bash
python -X utf8 D:\dumate\skills\news_script\gen_news_script.py
```

### 步骤5：验证产出
- PPT文件存在且 >100KB
- 邮件发送成功
- 公众号草稿media_id非空，5张内嵌图+封面图
- 新闻稿docx：年份为中文数字（二零二六），每条新闻≤200字且信息完整，5张配图已插入

## 新闻稿规则（V12生效）

### 配图规则（V12生效，用户强制）
- **严禁使用带台词/字幕/文字的图片**：搜索配图时，优先使用人物照片、新闻现场照、颁奖照、写真照等无字幕来源，避免使用电影/电视剧截图、台词字幕图、弹幕截图、字幕截图。关键词引导：搜索人物名+"照片""颁奖""写真""出席"，而非剧名+"剧照""台词"。
- 若配图含字幕/台词，必须重新搜索替换。

### 禁止百家号规则（V12新增）
- 搜索新闻时禁止采用百家号（baijiahao.baidu.com）内容
- 不得引用百家号文章作为新闻来源或数据出处
- websearch结果中如出现百家号链接，跳过不采用
- 每条新闻的2个以上消息来源中，不得包含百家号

### 字数控制与信息完整性规则（V12强化）
- 每条新闻口播内容（正文+分析合并后）截断至200字以内
- 超过200字时截断前197字 + `...`
- **信息完整性保证**：编写news_data.json时，body字段须在150字以内涵盖核心事实（人物+事件+关键数据），analysis字段须在80字以内给出核心观点，合并后不超过200字
- 截断后仍须保留：谁做了什么、关键数字、来源出处
- 严禁因截断丢失核心信息要素，宁可精简分析也不可丢失事实要素

### 日期中文数字规则
- 年份：`2026` → `二零二六`（标题、开场口播、片尾署名、文件名全部使用中文数字）
- 月份：`7月` → `七月`，`11月` → `十一月`
- 日期：`14日` → `十四日`，`20日` → `二十日`
- 正则兼容带空格格式：`(\d{4})\s*年`、`(\d{1,2})\s*月`、`(\d{1,2})\s*日`

## 全局规则（继承）

### 去重规则
每日须排除前一日已用新闻，同一新闻不连续两天出现。

### 消息来源规则
每条新闻消息来源不能单一，必须来自2个以上网站或官方网站。**禁止采用百家号作为消息来源。**

### 配图规则
- 强相关性：关键词从正文提取具体作品/人物名
- 时效性：用当下/近期数据
- overlay过滤：过滤带"指南""教程""培训"等配图
- 百度flip为主，3个URL+5秒超时，失败生成占位图
- 关键词不超过4个词组，过长则逐级缩短重试
- 压缩max 1200px/quality=85
- PIL中P/ARGB/LA/L模式转RGB

### PPT排版规则（V10全局生效）
动态布局引擎，y坐标基于前一元素底部+SAFE_GAP(0.12")；动态计算文本框高度；auto_size=None；行距1.35；word_wrap=True；正文宽Inches(7.5)；CHARS_PER_INCH=4.2。

### 公众号发布流程（5步强制）
Token → uploadimg(获取mmbiz.qpic.cn URL嵌入HTML) → add_material type=image(返回media_id作封面) → 内联HTML → draft/add(urllib避免中文乱码)。禁止用media/upload type=thumb。

### 邮件规则
- 163 SMTP smtp.163.com:465(SSL)，用户baihuahere@163.com
- 授权码存Windows用户级环境变量SMTP_163_AUTH_CODE
- PPT>50MB跳过邮件，≤50MB正常发送

### 写作规范
不同新闻事件严禁强行建立因果关系，分析影响基于单条新闻自身逻辑，不跨事件嫁接。
